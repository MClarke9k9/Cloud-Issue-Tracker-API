# Deployment

This repo includes a `render.yaml` blueprint for deploying the API and PostgreSQL database from GitHub.

## Render Blueprint

1. Push the repo to GitHub.
2. In Render, create a new Blueprint from the GitHub repository.
3. Render reads `render.yaml` and creates:
   - `cloud-issue-tracker-api`
   - `cloud-issue-tracker-db`
4. The Docker container runs:

```bash
npx prisma migrate deploy && node dist/src/server.js
```

## Required Environment Variables

- `DATABASE_URL`: supplied by the managed PostgreSQL database.
- `JWT_SECRET`: generated by Render.
- `JWT_EXPIRES_IN`: defaults to `1d`.
- `NODE_ENV`: `production`.

## Health Check

The service exposes:

```text
GET /health
```

The health route verifies both the API process and the database connection.
